拼豆 A4 打印样张 · 使用说明

本页不会打印。样张数据取自真实 color-palette.js（221 色）， 色号编码与黑白字判定与产品算法一致。下方 5 页是印刷版面本身。

⚠️ 先读这个：实测推翻了 PLAN 的一个前提

PLAN §4.3 给 52×52 主路径定的色号字号是 9.8pt（公式「每格 × 0.9 ÷ 1.0em」）。 该公式隐含假设 2 个字符合计占 1.0em（每字符 0.5em）。

probe-print-fit.js 用真实 Chrome 量了 全部 221 个 2 字符码，实测结果：

字体9.8pt 占格宽超格数真实字号上限
产品字体栈（YaHei）154%189 / 2215.74pt
Arial145%191 / 2216.10pt
Arial Narrow119%23 / 2217.43pt
Consolas（等宽）99%0 / 2218.92pt

结论：9.8pt 只在等宽字体下成立。用产品当前的字体栈，9.8pt 会让 189 个色号与邻格粘连。 本样张把几种字号并排印出来，请用眼睛定夺（第 2、3 页）。

怎么打印

  1. Ctrl+P → 目标选 另存为 PDF（先预览）或直接选打印机
  2. 纸张 A4；缩放 默认 / 100%（不要选"适应页面"，那会破坏物理尺寸，项 3 就白验了）
  3. 边距 默认（由样张的 @page 控制）
  4. 先不勾「背景图形」存一份，再勾上存第二份 —— 项 4 要分两次看

项 1：色号可读性（最高风险，决定 2 字符方案与字号）

✅ 本项已判定（见下）。判据如下，若要复核可看第 3 页（字号并排）与第 1/2 页（最终形态 vs 9.8pt 对照）。

  1. 哪个字号可用 —— 相邻格色号不粘连、且小写仍认得出（第 3 页并排多档）
  2. 大小写能否区分 —— 一眼看出 An 里哪个是大写；易混对 b/6、g/9、s/5 不混

第 3 页把最宽组合（Hm Mm 等）单独排成红框 —— 它们是最先粘连的， 红框里若已糊成一团，该字号就不能用。

若你觉得 6.4pt 已看不清 → 说明 52 列/页这条路走不通， 需要改"每页列数"（降密度），而不是硬压字号。见下方「密度方案」。

项 4：打印颜色管理（✅ 已定论，见下）

已实测确认（真实 Chrome Page.printToPDF，数 PDF 内容流里的彩色填充种数）：

⇒「不勾背景图形」恰好就是 §4.5 想要的「纯灰度 / 省墨模式」：色块不印，网格线与色号照印。

⚠️ 但请注意：本样张已刻意去掉 print-color-adjust: exact。 第一版加了它，导致该复选框彻底失效（不勾也是全彩，两份 PDF 一样）—— 这正是"看不出区别"的原因。实现产品时不要默认加死该属性，否则用户将失去省墨选项。

仍建议你在纸上确认两件事（只有真打印机才能定论）：

这一份应该看到
不勾背景图形色块消失，但网格线与色号仍在（应明显省墨）
勾上背景图形色块回来，网格线不消失、色号不变浅、无明显偏色

第 3 页底部有颜色对照块：纯色块看偏色、浅色调看"变浅"、网格线两种写法看是否一致。
