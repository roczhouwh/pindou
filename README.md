# 拼豆图纸生成器 🧩 `v0.5.1`

上传图片，自动生成拼豆（Perler Bead / MARD）图纸 —— 带色号标注、颜色统计、高清导出。

## 功能

- **📷 拍照上传** — 移动端直接用原生相机拍照取图，无需先存相册
- **🖼️ 图片上传** — 拖拽或点击，支持 JPG / PNG / WebP，最大 20MB
- **✂️ 自由框选** — 拖拽选区 + 8 个手柄精确调整，滚轮缩放，右键平移
- **👆 双指操作** — 移动端双指缩放/平移，选框外单指平移图片
- **🎨 色板映射** — MARD 221 色标准色板，RGB 欧氏距离最近邻自动匹配
- **📐 多尺寸网格** — 预设 29×29 / 52×52 / 78×78 / 104×104，支持自定义 15~104，选框内容完整放入网格（contain 居中）
- **🏷️ 色号标注** — 每个格子上标注对应色号，深色格白字、浅色格黑字
- **📏 行列标尺** — 图纸外侧标注行号列号，每 10 格一条加粗参考线，照着拼不会数错。
  格子够大时逐格标，格子小（52×52 以上）自动改为每 5 格标一次；可开关，默认开启
- **📊 颜色统计** — 按用量排序的颜色表，一目了然需要多少颗豆
- **🎯 颜色简化** — 滑块 0-100%，合并相近色，减少颜色种类
- **📥 PNG 导出** — 2x 高清下载，含网格图 + 色号 + 颜色对照图例
- **🖨️ A4 打印** — 直接打印矢量图纸（不是截图，色号由打印机按自身分辨率渲染，多清晰都锐利）。
  每页 52 列、每格 3.846mm，**52×52 正好一张 A4**；104×104 分成 4 页 2×2 拼接，
  每页都标好「第 N/4 页 · 第 X 行第 Y 块 · 列 a-b / 行 c-d」，照着拼不会接错。
  点打印前就会告诉你**会出几页、每格多大**
- **🖨️ 省墨模式** — 取消勾选「打印色块」，就只印网格线和色号、不印色块底色。
  灰度打印下色号是唯一信息源，照样能照着拼
- **💾 图纸存档** — 生成后给图纸起个名字存下来（**存在你自己的浏览器里，不会上传到任何服务器**），
  下次打开可**直接载入查看 / 导出 / 打印**，不需要再找原图。可存多份、可删除（删除前会确认）。
  ⚠️ 存档**只保存图纸本身**（色号与空格），**不含原图** ——
  所以载入存档后会进入「**无原图模式**」：网格尺寸与颜色简化需要重新采样原图，
  此时会**置灰并说明原因**；上传一张图片即可继续调整
- **📤 分享** — 支持一键分享图纸到其他应用
- **📌 离线可用** — PWA 支持，添加到主屏幕后离线也能使用
- **🔄 重置选框** — 一键恢复选区到默认位置
- **📱 iOS 兼容** — 支持 iOS 14.4+，选框 canvas 双保险绘制，预览自动适配小屏

## 使用方式

> ⚠️ **必须先起一个本地 HTTP 服务，不能再直接双击 `index.html`。**
>
> 本项目用的是浏览器**原生 ES module**（`<script type="module">`）。
> 按浏览器安全策略，`file://` 协议下**模块脚本会被 CORS 拦下、根本不执行** ——
> 双击打开只会看到一个**没有样式的空壳页面**，功能全无。
>
> 这是改用原生 ESM 换来的代价（收益：不再需要靠 `<script>` 标签顺序维护依赖、
> 模块边界清晰），**仍然是零依赖、无需安装、无需构建**。

### 方式一：HTTP 服务（推荐）

任选一种起服务的方式，**在项目目录下**执行：

```bash
python3 -m http.server 8080
# 或
python -m http.server 8080
# 或（装了 Node 的话）
npx serve .
```

然后访问 <http://localhost:8080>。

> 只需一条命令，不需要 `npm install`，也不需要打包。

### 方式二：PWA 安装（离线可用）

1. 先用上面的方式一在 Chrome 或 Edge 中打开
2. 地址栏出现安装图标（或底部横幅提示）
3. 点击"添加到主屏幕"
4. 之后可离线使用，享受全屏 APP 体验

> Service Worker 只在 `http://localhost` 或 HTTPS 下生效 —— 这也是必须起服务的原因之一。

## 怎么打印成 A4 图纸

生成图纸后，点控制栏的 **🖨 打印 A4** 即可。按钮旁边会先显示**会出几页、每格多大**，
确认合适再点。

打印对话框里建议：

| 项 | 选什么 |
|---|---|
| 纸张 | **A4** |
| 缩放 | **默认 / 100%** —— ⚠️ **不要选"适应页面"**，那会破坏每格的物理尺寸 |
| 边距 | **默认**（版面自己控制 5mm 边距） |
| 背景图形 | **不勾** = 省墨模式（只印网格线与色号，不印色块）；**勾上** = 印色块 |

> 💡 **色号是矢量文字**，不是图片。所以打印机是 300dpi 还是 600dpi，色号都一样清晰 ——
> 这是打印出口相对"导出 PNG 再打印"的核心优势（PNG 里没有物理尺寸，
> 同一张图打印出来可能是 49cm 宽，也可能每格只有 1.9mm）。

**拼大图**：104×104 会分成 **4 页 2×2 拼接**，每页右上角都标注了
「第 N/4 页 · 第 X 行第 Y 块 · 列 a-b / 行 c-d」，按标注顺序拼起来即可。
每页的格子尺寸完全相同，拼得上。

> ⚠️ **灰度/黑白打印完全可用**：不勾「背景图形」时色块不印，
> 但网格线与色号照印 —— 灰度下色号本就是唯一信息源。

## 怎么保存和载入图纸

生成图纸后，在页面上方的「**图纸存档**」区：

1. 给这份图纸**起个名字**（例如「小猫头像」）
2. 点 **💾 保存图纸** —— 存进**你自己的浏览器**（不会上传到任何服务器）
3. 之后任何时候打开这个页面，在下拉框里选中它，点 **📂 载入** 即可

载入后可以直接**看预览、看颜色统计、下载 PNG、打印 A4**，不需要原始照片。
不需要的存档可以选中后点 **🗑 删除**（会先问一次，删了不可恢复）。

> ⚠️ **载入存档后会进入「无原图模式」** —— 因为存档里只保存**图纸本身**
> （哪一格是什么色号），**不保存原图和选框**。此时：
>
> - 「网格尺寸」与「颜色简化」会**置灰**，并在上方说明原因：
>   这两项都要**重新采样原图**才能算，没有原图就做不到；
> - 想继续调整，**上传一张图片**即可 —— 控件会自动恢复可用。
>
> 这样做是刻意的：如果保留原图，选框框住的区域与载入进来的图纸内容会对不上，
> 界面会自相矛盾。宁可说清楚"现在能做什么"，也不给一个会对不上的界面。

> 💡 **换个浏览器 / 清了浏览数据，存档就没了** —— 它保存在本机浏览器里，
> 不会同步到其它设备。想长期留存或分享，请**下载 PNG** 或**打印 A4**。

## 技术栈

原生 HTML / CSS / JavaScript，**零依赖、零构建**，Canvas API 完成所有图像处理。
模块化使用浏览器**原生 ES module**（`import` / `export`），无需打包工具。
PWA 标准：manifest.json + Service Worker。

## 文件结构

```
index.html          — 页面结构（上传区 / 查看器 / 控制栏 / 预览 / 拍照 / 加载动画 / 安装提示）
                       ⚠️ 只有一个 <script type="module" src="js/main.js">（ESM 单入口）
style.css           — 样式（响应式布局，触摸设备适配，安全区域）
color-palette.js    — MARD 221 色板 + 颜色匹配（ESM 模块）

js/core/            dom.js       — DOM 引用与基础助手
                    state.js     — 全局状态与常量
                    serialize.js — 图纸序列化 / 版本化（存档格式）
                    storage.js   — 图纸存档存储层（浏览器本地保存，多份管理）
js/input/           upload.js    — 图片上传与提示
                    camera.js    — 拍照录入
js/viewer/          viewer.js    — 查看器渲染与几何计算
                    selection.js — 选框拖拽
                    panzoom.js   — 缩放 / 平移 / 双指手势
js/pipeline/        grid.js      — 逐格采样与色板映射
                    simplify.js  — 近似色合并
                    render.js    — 网格绘制与行列标尺
js/output/          preview.js   — 预览渲染
                    stats.js     — 颜色用量统计
                    export.js    — PNG 合成与下载 / 分享
                    print.js     — A4 打印出口（2 字符色号编码 / 分页 / 打印版面）
js/ui/              a11y.js      — 无障碍播报与键盘操作
                    grid-select.js — 网格尺寸与简化滑块
                    library.js   — 图纸存档的保存 / 载入 / 删除界面
                    loading.js   — 加载遮罩
                    install.js   — PWA 安装提示
js/main.js          — **模块入口**（导入上面全部模块，把整张模块图拉起来）

manifest.json       — PWA 清单
sw.js               — Service Worker
icon.svg            — 应用图标源文件
icon-192.png        — 192×192 PWA 图标
icon-512.png        — 512×512 PWA 图标
CLAUDE.md           — 开发文档（面向 AI 的技术说明）
docs/PLAN.md        — 开发计划与执行进度
docs/REFACTOR.md    — 代码结构对策
docs/REVIEW.md      — 代码审查报告
```

> **改完代码记得递增 `sw.js` 里的 `CACHE_NAME`** —— 它是 cache-first，
> 不换版本号老用户会一直拿到缓存里的旧文件。

> ⚠️ **新增模块时必须在 `js/main.js` 里补一条 `import`**（若它不被其它模块引用）。
> 浏览器是**从入口的 import 出发**加载模块的 —— 没被 import 到的文件
> **根本不会被请求**，页面会静默少功能，而且**跑测试也发现不了**。
> 细节见 [docs/REFACTOR.md](docs/REFACTOR.md) §8.7。
